# 06 · keystroke-basics

**What:** The no-frills BadUSB — opens Terminal (macOS) and types a harmless `echo`. Demo 01
without the lights/siren, so you can see the bare attack.

**Arm:** slide switch to the left. Fires once; toggle off/on to repeat.

**Lesson:** Keystroke injection is just a "keyboard" typing fast. Whatever you can type, it can
type — including shell commands.

**Defense:** lock your screen when away; USB device control / allow-listing on sensitive machines.
